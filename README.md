# Knowledge Library Standard

**This is a standard, not a claim that the library already exists.**

Put it on screen. Show the distinction. Do not claim the system is built.

## Six parts

1. Knowledge should be discoverable. Trust should be earned.

2. Not everything submitted will be verified, and that is why the status has to be visible.

3. Unverified, Under Review, Verified, Disputed, Withdrawn. Only Verified carries the mark.

4. A verified entry has to name what, who, evidence, when, and limits.

5. People can challenge, correct, and add. Earlier versions stay.

6. Open contribution. Visible evidence. Earned trust. **PROOF NOT PROMISE.**
